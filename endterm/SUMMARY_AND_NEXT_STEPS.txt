═════════════════════════════════════════════════════════════════════════════════
WHY DATA CURATION FAILED
═════════════════════════════════════════════════════════════════════════════════

1. ROOT CAUSE: High Variance in Target Variable
   • CLTV ranges from 25k to 720k (29x range!)
   • Some CLTV values are INHERENTLY UNPREDICTABLE
   • Model needs to see the full distribution to learn proper scaling
   
2. "GOOD" IS NOT A GENERALIZABLE PATTERN
   • Good predictions cluster in low-CLTV region (correlation, not causation)
   • Filtering by this correlation → overfitting to subset
   • Model can't generalize to test set which has full distribution
   
3. LIMITED FEATURES & DATA
   • Only 10 original features
   • Missing customer behavior history, temporal data
   • With sparse features, every sample matters for learning
   • Can't afford to throw away 85% of data

4. MATHEMATICAL REASON:
   • Removing 85% of training data = removing 85% of signal
   • Benefits from "good" focus don't outweigh information loss
   • Weighted training is too subtle (15% signal vs 85% noise ratio)

CONCLUSION & INTERPRETATION
═════════════════════════════════════════════════════════════════════════════════

The professor's suggestion to analyze "good" predictions was VALUABLE but revealed
a fundamental limitation rather than a solution:

✓ CORRECT DIAGNOSIS:
  • Model struggles with high-variance targets
  • Some values more predictable than others
  
✗ DATA CURATION NOT THE ANSWER:
  • Attempts to filter/weight the data made things worse
  • Root cause is INSUFFICIENT FEATURES, not bad data
  • Model has already learned what it can from these 10 features
  
→ NEXT FRONTIER:
  • Better feature engineering (domain knowledge)
  • More/different data (behavioral, temporal)
  • Alternative modeling approaches
  • But NOT data curation filtering

FINAL THOUGHT
═════════════════════════════════════════════════════════════════════════════════

This analysis demonstrates that NOT all problems can be solved through data
curation. When features are sparse and target variance is high, the model needs:

  ✓ Full spectrum of training data
  ✓ Better features (engineering or collection)
  ✓ More sophisticated algorithms
  ✗ NOT selective filtering

The professor's direction to analyze the data was insightful and led to
understanding the model's behavior better. The lesson: sometimes understanding
WHY something doesn't work is as valuable as making it work.
